# 城市共好島｜單機互動政策地圖

這是第六堂課的網頁實作練習。作品研究「政策島」以縮微城市呈現公共政策的互動方式，再以原創 SVG、虛構政策內容與純前端技術，重做成可離線使用的單機版網頁。

## 功能

- 十座可點選的政策島嶼
- 政策清單與關鍵字搜尋
- 政策細項、服務對象與協作主題
- 清晨、白天、黃昏、夜晚四種城市光影
- 桌面與手機響應式版面
- 鍵盤操作、焦點樣式與減少動態效果支援
- 無外部套件、字型或圖片請求，可直接離線開啟

## 使用方式

直接以瀏覽器開啟 `index.html` 即可。也可以在此資料夾啟動任何靜態網頁伺服器。

## 檔案

- `index.html`：網頁結構與原創 SVG 島嶼場景
- `styles.css`：視覺、動畫、日夜模式與響應式版面
- `app.js`：政策資料、搜尋、清單與互動邏輯

## 聲明

本作品為課堂教學範例，政策與城市皆為虛構內容，並非任何真實機關、候選人或政策宣傳。視覺與程式碼均為重新設計，不含原網站圖像素材。
